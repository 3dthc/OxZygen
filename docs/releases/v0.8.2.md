# OxZygen v0.8.2

## What's new
- **New card on the MPC Sounds screen:** the OXZYGEN tile now matches the current look, with the chamber's lit vent slats behind a brushed-metal nameplate, replacing the old orb picture.
- **The data wheel works on the Browse page:** turn Q-Link 1 or 2 and the wheel follows the same control, stepping through banks or presets.

## Fixed
- **Browse page Q-Links:**
  - The preset Q-Link moved several presets per click; it now moves one preset per detent.
  - At the end of a category it got stuck on a "Null" value with numbers; it now stops on the last preset and turns straight back.
  - The page now shows a single Q-Link group: Q-Link 1 = bank, Q-Link 2 = preset.

Sound, presets and saved projects are unchanged.
